# SVG Presentation Attribute Types

## What changed

Added `SVGPresentationAttrs` and seven sibling types to `svg.ts`, threaded them through a new `S` type parameter on `makeSVGElement`, and removed the `& { [key: string]: unknown }` escape hatch from `Attrs<E, S>` in `dom.ts`.

## Key decisions

- **`S` generic, not a parallel type** — `Attrs<E, S>` already had an `S = object` slot. Every SVG element attribute type flows through that slot; no new abstraction was needed.
- **`SVGAnimationTimingAttrs` intentionally omits `SVGPresentationAttrs`** — animation elements have a `fill` attribute meaning `"freeze" | "remove"`, not a paint color. Merging both types would make `fill` accept a union of unrelated values, defeating the purpose.
- **Escape hatch removed, not narrowed** — the `& { [key: string]: unknown }` was all-or-nothing; narrowing to `data-*` or similar was considered but not needed by any call site in this repo.

## Discoveries

- `dom.ts` had the escape hatch added as a downstream workaround (astrolabe project). Removing it required no changes outside `dom.ts` and `svg.ts` — all existing call sites already used known-typed attributes.
